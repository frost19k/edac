## What's NOT Done
The plugin needs to be written as a **single bundled `.ts` file** to `~/.config/opencode/plugins/holographic-memory.ts`.

**WHY a single file**: OpenCode loads plugins from `~/.config/opencode/plugins/` as individual files. The multi-file source in `src/` won't work there because relative imports (`./store`, `./hrr`, etc.) won't resolve.

## How to Install (the ACTUAL way — read the docs at https://opencode.ai/docs/plugins)
1. Bundle all 6 source files into ONE self-contained `.ts` file
2. Write it to `~/.config/opencode/plugins/holographic-memory.ts`
3. That's it. OpenCode auto-loads it at startup. No `bun add`, no npm, no plugin array in opencode.json needed for local plugins.
4. The only dependency is `@opencode-ai/plugin` which is already installed in `~/.config/opencode/node_modules/`
5. `bun:sqlite` is a Bun built-in — no install needed
