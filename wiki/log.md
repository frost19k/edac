## [2026-08-18] edit | Wildcard matching semantics documented — verified against `packages/opencode/src/util/wildcard.ts` (`match()` + `all()`) fetched from `sst/opencode` `dev`. Four facts the wiki previously omitted: (1) **full-string anchored** matching (`^pattern$`) — `"git status *"` does not match `xgit status foo`; (2) **trailing ` *` is optional-aware** — the matcher rewrites a trailing ` *` to `( .*)?`, so `"python *"` matches both `python` (no args) AND `python -c foo` (a separate no-args entry is unnecessary); (3) **`"cmd *"` vs `"cmd*"`** — the space is a poka-yoke delimiting command from args; `"python*"` (no space) overmatches `python3`/`pythonista`, so `"cmd *"` is the correct form for a single binary; (4) **evaluation is sort-by-length** (alphabetical tiebreak), not source-order — catch-all `"*"` (length 1) always sorts first, so "declare catch-all first" produces correct behavior, but the mechanism is length-sorted last-match-wins. Corrects a prior reasoning error (SystemBuilder had claimed `"python *"` does not match bare `python` — false, the trailing-optional rule covers it).
